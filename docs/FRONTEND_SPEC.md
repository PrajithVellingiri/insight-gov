# Frontend Specification

## Responsibility

Frontend is responsible only for the user interface.

Never implement backend logic.

Never implement AI logic.

---

## Responsibilities

- Authentication UI
- Citizen Portal
- Officer Dashboard
- Admin Dashboard
- Petition Forms
- Tables
- Charts
- Maps
- Responsive Design

---

## Technology

- React
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
- React Query
- Axios
- Leaflet
- Recharts

---

## Rules

- Reusable Components
- Mobile Responsive
- Accessible UI
- Modern Design
- Clean Folder Structure
- No Hardcoded Data
- Consume Backend APIs only
- Never redesign APIs
