# Backend Specification

## Responsibility

Backend handles business logic and APIs.

Never build frontend.

Never implement AI algorithms.

---

## Responsibilities

- Authentication
- JWT
- Database
- REST APIs
- Validation
- Authorization
- Officer Assignment
- Petition Management
- Analytics APIs

---

## Technology

- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT
- Pydantic

---

## Rules

- RESTful APIs
- Layered Architecture
- Service Pattern
- Repository Pattern
- Input Validation
- Secure Endpoints
- Clean Error Handling
- Never generate UI
